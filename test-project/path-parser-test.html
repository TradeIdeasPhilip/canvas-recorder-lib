📐 Path parser test

Checks PathShape.fromRawString() against the browser's own reader, new Path2D(d), which understands every SVG path command. Each picture has the browser's version underneath, wide and pink, and ours on top, thin and dark. If ours wanders outside the pink, or the pink shows a stroke ours doesn't have, it fails. The same check runs on the pixels, and the result is below each picture.
